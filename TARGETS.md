# MineIPTV targets

- Minecraft 1.21.1
- NeoForge 21.1.256+
- Java 21
- Official NeoForge ModDevGradle 2.0.148 build configuration

The `build/neoforge-1.21.1` branch is audited and built specifically for this target. Other Minecraft/loader combinations remain development targets until they receive the same build and runtime verification.
